Automatic backup

After every change, while you're online, Trip Ledger locks your data with your passphrase and saves it to your private GitHub repository. Nobody, including GitHub, can read it without the passphrase. Each save is kept as a version, so you can go back.

Write the passphrase down. If it's lost, the backup can't be opened by anyone.
